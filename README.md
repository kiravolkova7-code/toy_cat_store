# Toy Cat Store
## Описание
Проект учебного интернет-магазина по продаже игрушечных котов. 

**В рамках первого модуля** реализована базовая структура проекта на `Django`: 
настроено виртуальное окружение, подключен `GitFlow`, созданы основные страницы 
(Главная и Контакты) с использованием `Bootstrap`.

**В рамках второго модуля:** проект переведен на СУБД `PostgreSQL`, реализована 
бизнес-логика каталога: созданы модели `Product` и `Category`, настроена административная 
панель, база данных наполнена через `Django Shell`, а также реализованы фикстуры и кастомная 
команда для генерации тестовых данных.

**В рамках третьего модуля:** реализация детальной страницы товара, оптимизация верстки через наследование 
шаблонов и создание универсального списка товаров на главной странице.

**В рамках четвертого модуля:**
- Весь код контроллеров приложения `catalog` переведен с функциональных представлений (`FBV`) на 
классовые представления (`CBV`).
- Создано новое приложение `blog` для улучшения видимости сайта в поисковых системах (`SEO`). 
- Реализован полный `CRUD` для управления записями, добавлена логика подсчета просмотров и фильтрации 
опубликованных материалов.

**В рамках пятого модуля:**
реализован полный `CRUD`-интерфейс для управления товарами, добавлена защита от спама при создании продуктов, 
а также реализована загрузка изображений с проверкой формата и размера файла.

**В рамках шестого модуля (Пользователи):**
- Создано приложение `users` с кастомной моделью пользователя на базе `AbstractUser`. Поле `username` удалено, 
авторизация происходит по уникальному адресу электронной почты.
- Добавлены поля профиля: аватар (`ImageField`), номер телефона и страна проживания.
- Реализована регистрация пользователей с отправкой приветственного письма после создания учетной записи.
- Настроена авторизация по `email` и паролю.
- Введены ограничения доступа к управлению продуктами: анонимные пользователи могут только просматривать список 
товаров; все действия `CRUD` доступны исключительно авторизованным пользователям.

**В рамках седьмого модуля (Модерация и права владения):**
- К модели продукта добавлено поле статуса публикации (по умолчанию — неопубликовано) и поле владельца (`owner`).
- Реализована автоматическая привязка создаваемого продукта к текущему авторизованному пользователю.
- Создана группа «Модератор продуктов» с правами на удаление любого продукта и снятие его с публикации 
(кастомное право `can_unpublish_product`).
- Реализована проверка прав: редактировать и удалять продукт может только его владелец или пользователь из группы модераторов.
- Интерфейс адаптирован под новые права: кнопки редактирования и удаления отображаются только владельцу.

**В рамках восьмого модуля (Оптимизация и кеширование):**
- Проект интегрирован с брокером сообщений `Redis` для организации кеширования.
- Реализовано низкоуровневое кеширование списка продуктов.
- Настроено кеширование детальной страницы информации о продукте.
- Создана сервисная функция, представление и шаблон для вывода всех продуктов конкретной категории.

## Функционал
- **Навигация:** переход между главной страницей (`/`), контактами (`/contacts/`), категориями и детальными страницами товаров.
- **Рендеринг шаблонов:** отображение HTML-разметки через контроллеры приложений `catalog` и `users`, использование `DTL` для вывода данных из БД.
- **Стилизация:** адаптивная верстка страниц с использованием фреймворка Bootstrap.
- **Маршрутизация:** централизованное управление URL-адресами с использованием функции `include`.
- **Каталог:** вывод списка категорий и товаров из базы данных `PostgreSQL`.
- **Администрирование:** управление категориями, продуктами и пользователями в панели администратора.
- **Работа с данными:** заполнение БД через `shell`, использование фикстур и кастомных `management`-команд.
- **Детальная страница продукта:** отображение полной информации о товаре с применением кеширования.
- **Оптимизация кода:** выделение общих блоков интерфейса в базовые шаблоны и подшаблоны.
- **Блог:** публикация статей со счетчиком просмотров.
- **Управление продуктами:** полная реализация операций `Create/Read/Update/Delete (CRUD)` для модели `Product`.
- **Защита от спама:** автоматическая проверка названий и описаний новых товаров на наличие запрещенных слов.
- **Загрузка изображений:** прикрепление к товару изображений форматов `JPEG` или `PNG` размером до `5 МБ`.
- **Аутентификация:** регистрация по email с подтверждением, вход в систему по почте и паролю.
- **Авторизация и RBAC:** разграничение прав доступа для обычных пользователей, владельцев продуктов и модераторов.
- **Кеширование:** использование `Redis` для снижения нагрузки на базу данных при работе со списками и деталями товаров.
- **Валидация данных:** дополнительные проверки полей формы (например, цена не может быть отрицательной).
- **Адаптация интерфейса:** стилизация всех форм создания и редактирования под общую стилистику сайта.



## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/kiravolkova7-code/toy_cat_store.git
```
2. Создайте и активируйте виртуальное окружение:
Для Windows:
```
python -m venv venv
.\venv\Scripts\activate
```
3. Скопируйте шаблон файла окружения и заполните его своими данными:
```
cp .env.example .env
```
Заполните переменные `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT` в файле `.env`.

4. Установите зависимости из файла:
```
pip install -r requirements.txt
```
5. Примените миграции:
```
python manage.py migrate
```
6. Запустите сервер разработки:
```
python manage.py runserver
```

## Зависимости
Все необходимые пакеты указаны в файле `requirements.txt`.
